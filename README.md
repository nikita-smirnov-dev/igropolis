# Многостраничный сайт на Astro

## О проекте

Этот проект — многостраничный веб-сайт, созданный в процессе прохождения мастер-класса на платформе Stepik.

Целью было познакомиться с современным инструментом Astro и закрепить базовые навыки веб-разработки:

- работа с компонентами
- структура проекта
- маршрутизация страниц
- стилизация

Важно: проект выполнен в формате "повторения за автором" (code-along), чтобы лучше понять практическое применение технологий.

---

## Используемые технологии

- Astro
- HTML
- SCSS
- JavaScript

---

## Как запустить проект

1. Установить зависимости:

```
npm install
```

2. Запустить локальный сервер:

```
npm run dev
```

3. Открыть в браузере:

```
http://localhost:4321/
```
